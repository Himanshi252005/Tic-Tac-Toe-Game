# Tic-Tac-Toe

A two-player browser Tic-Tac-Toe game built in vanilla JavaScript.

## Built With
HTML5 · CSS3 · JavaScript (DOM manipulation)

## Features
- Two-player turn-based gameplay
- Win and draw detection across all winning combinations
- Reset / new game control

## Run Locally
```bash
git clone https://github.com/Himanshi252005/Tic-Tac-Toe-Game.git
cd Tic-Tac-Toe-Game
# open index.html in your browser
```
